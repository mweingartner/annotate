# Implementation contract

Native macOS 26+ application, Swift 6.2+, SwiftUI + AppKit + PDFKit + CoreGraphics; no third party dependencies. Build with Swift Package Manager, package a native .app. Root owns app model, NSDocument lifecycle, PDFView bridge, package/install scripts and integration.

Core agent owns Sources/AnnotateCore exclusively. Public value types (Codable, Equatable, Sendable): MarkerCategory (.important, .revisit, .question, .note; raw String; title, symbol), MarkerColor (red,green,blue Double; init(red:green:blue:); nsColor, static palette: [MarkerColor]), PageRegion (pageIndex Int, bounds CGRect), PDFMarker (Identifiable UUID id, categories Set<MarkerCategory>, color MarkerColor, icon String SF Symbol, quote String, note String, question String, regions [PageRegion], createdAt Date; public init with defaults for id/date, all others labeled); computed pageIndex first region or 0. Enum MarkerFilter (.all,.important,.revisit,.question,.note), title, symbol, matches(PDFMarker).

Public @MainActor enum MarkerCodec: static markers(in: PDFDocument) -> [PDFMarker]; static apply(_ marker: PDFMarker, to: PDFDocument) throws; static remove(id: UUID, from: PDFDocument); static regions(for: PDFSelection,in: PDFDocument)->[PageRegion]. Embed bounded, versioned JSON metadata in standard annotations using a custom PDF key; render multiline highlights plus a visible icon. Preserve other applications' annotations. Apply replaces prior same-id annotations. Validate data from disk. PDF dataRepresentation must roundtrip marker metadata. Human-readable annotation contents include category, quote, note and question.

Public @MainActor enum PDFExporter: static flattenedData(document: PDFDocument, markers: [PDFMarker], includeNotes: Bool = true) throws -> Data. Flatten source pages and visible annotations with correct crop/rotation, retaining vector text when possible. Append fully paginated readable notes/questions index, with source page references. Do not silently omit long notes. Exported PDF must have no annotation objects. Enforce PDF permissions.

UI agent owns Sources/AnnotateApp/Views only: ReaderView(model: ReaderModel), MarkerSidebar(model:), MarkerInspector(model:), WelcomeView(model:), other view components. Root provides PDFReaderView(model:). ReaderView includes native toolbar controls, status/footer, animated sliding panels; marker list filters, result snippets; draft saves/cancels explicitly; arbitrary ColorPicker and preset swatches; several SF symbol options; notes and questions independently editable alongside important/revisit categories. Keyboard commands root-owned. Follow SwiftUI Pro, accessibility labels, Reduce Motion, native light/dark.

Test agent owns Tests, Docs/TEST_PLAN.md and Sources/AnnotateCore/SamplePDF.swift only. Public @MainActor enum SamplePDF { static func make() -> PDFDocument } with multiple selectable-text pages for practical demo. Core tests via Swift Testing should cover serialization, malformed metadata, exact line bounds, multi-page selections, replacement/delete preservation, filters, colors, flattening (rotation, crop, long notes, metadata removed, text preserved), invalid PDFs where relevant. Coordinate API changes before modifying another owner's file.
